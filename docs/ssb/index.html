Smart Storyboard

The Smart Storyboard was developed during the project to enable collaborative design and development of courses and learning experiences. The tool was developed after the teams initial work was frustrated by the lack of robust tools to aid design and development work. The central aim for developing this in-house was to tackle key problem areas that we encountered every time we developed a new course and to replace existing practices based on updating static documents:

  • The tool needed to manage workflow throughout course development process
  • Allow tasks, statuses, and responsibility to be assigned to different aspects of the course
  • Break the course into manageable scaffolded components that could facilitate multiple authors and collaborators
  • Aid the coordination of media and course build
  • Allow the course to be developd using the same visual style as the Learning Management System
  • Procide automatic real-time reporting using detailed tracking data

The tool was iterated on throughout the project with new features and refinements taking place throughout. What we ended up with was a tool that provided the team with an authoring environment that enabled the modular design courses and enabled an agile workflow, with tools that aided the development of quality learning experiences.

Smart Storyboard allowed the team to implement the innovative pedagogical elements - Learning Types and Patterns - and allowed these to be mapped across the course as a whole.
